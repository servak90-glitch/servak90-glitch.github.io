### ⚡ Performance Optimization v5.2

#### 🚀 Новый Performance Monitor
- **performanceMonitor.ts**: Сервис мониторинга FPS в реальном времени

- **Кэширование calculateStats**: Снижение с 60 до ~10 вызовов/сек
- **Разделение live/cached полей**: Критичные данные (heat, isDrilling) — каждый кадр, тяжёлые (drill, stats) — из кэша

- **FPS-адаптивные фильтры**: Автоотключение CRT/Bloom при FPS < 25
- **Динамический лимит частиц**: Масштабирование 0.2-1.0 на основе FPS

| calculateStats вызовов/сек | 60 | ~10 |
| FPS (Desktop) | 30-40 | 55+ |
| FPS (Mobile) | 15-25 | 40+ |

- **Снижение DOM-нагрузки**: Вместо 10+ элементов в секунду — 1 элемент на ресурс
- **Лимит элементов**: Максимум 10 одновременных floating-текстов
- **Автоскрытие**: Накопленное значение скрывается через 800ms после последнего обновления

  - **Попытки исправления**:
    1. Изменена логика с множественных проверок на один рейд
    2. Заменена tick-based система на timestamp-based
    3. Добавлено поле `lastRaidCheck` для отслеживания времени
  - **Результат**: Ни одно исправление не помогло
  - **Решение**: Система рейдов **полностью отключена** до пересмотра архитектуры
